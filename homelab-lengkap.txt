A. HOMESERVER CORE — Level 1 (WAJIB)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

□ Docker + Docker Compose
  Pondasi. Semua service jalan di sini.

□ Portainer
  UI Docker dari browser — gampang pantau container.

□ Nginx Proxy Manager
  Domain + SSL (HTTPS) otomatis. WAJIB biar semua service 
  punya subdomain rapi. Contoh:
  └ mail.domain.com → Mailcow
  └ cloud.domain.com → Nextcloud  
  └ ha.domain.com → Home Assistant
  └ ai.domain.com → AI Agent

□ Cloudflare Tunnel (alternatif NPM)
  Kalau gak punya IP publik. Tunnel langsung dari Cloudflare.

□ WireGuard VPN
  Akses server dari luar rumah. Aman tanpa buka port.

□ Uptime Kuma
  Monitoring: service mati → notifikasi Telegram.

□ Watchtower
  Update container otomatis biar gak usah manual.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
B. PENYIMPANAN & FILE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

□ Samba / NFS
  File sharing jaringan lokal.

□ FileBrowser
  Web UI file manager — upload/download lewat browser.

□ Nextcloud
  Google Drive versi self-hosted. 
  Sync file + kalender + kontak + foto dari HP.

□ Syncthing
  Sync folder antar device langsung (HP-Laptop-Server).
  Alternatif Nextcloud kalau cuma butuh sync file doang.

□ Duplicati / Restic
  Backup otomatis ke cloud (Google Drive, S3, Backblaze).

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
C. SMART HOME — Otomasi Rumah
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

□ Home Assistant (Core/OS via Docker)
  ⭐ Pusat smart home. Linking semua device pintar.
  └ Lampu, saklar, sensor suhu, CCTV
  └ Otomasi: "sensor hujan → jemuran masuk"
  └ Dashboard sendiri di HP

□ ESPHome
  Buat sensor sendiri pakai ESP32/ESP8266.
  └ Sensor suhu kamar
  └ Sensor kebocoran gas
  └ Detektor gerak
  └ Modal Rp 30–100rb per sensor

□ Zigbee2MQTT + Zigbee Dongle
  Untuk device Zigbee (sensor Xiaomi, Aqara, Philips Hue).
  └ Dongle: Sonoff ZBDongle-P ~Rp 150rb
  └ Lebih stabil dari WiFi

□ Mosquitto (MQTT Broker)
  Tulang punggung komunikasi antar device smart home.

□ Node-RED
  Automasi visual kayak flowchart.
  └ "Kalau maghrib → lampu teras nyala"
  └ "Kalau suhu >30°C → kipas nyala"

□ Frigate NVR (CCTV AI)
  Kamera RTSP → deteksi orang/mobil/hewan pake AI lokal.
  WAJIB kalau pasang CCTV.

□ Scrypted / Homebridge
  Biar gak support (Xiaomi/Tuya) bisa masuk HomeKit.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
D. AI AGENT PRIBADI
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

□ Hermes Agent
  Yang kamu pakai sekarang. Jalanin 24/7 di server.
  └ Bot Telegram pribadi
  └ Jadwal sholat, pengingat, catatan harian

□ Ollama (LLM lokal)
  Jalanin model AI tanpa internet (Mistral, Llama, Qwen).
  └ Minimal 16GB RAM untuk model 7-8B
  └ Cocok buat chat AI pribadi — privasi terjaga

□ Open WebUI
  UI kayak ChatGPT tapi pake Ollama lokal.
  └ Akses dari HP laptop kapan aja

□ N8N
  Automasi workflow.
  └ Auto-scrape harga kompetitor rental
  └ Auto-reply WA dengan AI
  └ Jadwal posting konten

□ ComfyUI (optional)
  Generate gambar pake AI lokal.
  Butuh GPU, tapi bisa jalan di CPU (lambat).

□ Whisper (STT lokal)
  Ubah suara ke teks — buat catatan voice-to-text.

□ Piper TTS (lokal)
  Ubah teks ke suara — buat voice assistant rumah.

E. DATABASE & INFRA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

□ PostgreSQL + Adminer
  Database utama buat project.

□ InfluxDB + Grafana
  └ Simpan data sensor rumah (suhu, kelembaban)
  └ Grafana dashboard — visualisasi data realtime

□ Redis
  Cache, session, queue. Berguna kalau ada web app.

  GitHub pribadi — simpan coding project.

□ Code-Server (VS Code di browser)
